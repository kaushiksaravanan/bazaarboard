# Hyperframes composition — next steps

This directory is scaffolded for the vertical 22s brag video. The composition itself is authored by the `hyperframes` skill using the two docs one level up.

## Inputs the composer must read (in order)

1. `../composition-brief.md` — the boundary contract
2. `../brag-plan.md` — the creative rubric + storyboard
3. `../script.md` — exact on-screen copy and timings
4. `../../../src/app/page.tsx` — for palette, layout patterns, ThroughputBar, AllScriptsStrip
5. `../../../src/lib/languages.ts` — for the 8 native-script phrases and their font classes

## Handoff commands (run in this directory)

```bash
# Copy the music track first
mkdir -p composition/assets/music
cp ~/.claude/skills/brag/assets/music/vol-12.mp3 composition/assets/music/

# Detect beats for vol-12
cd composition && npx hyperframes beats assets/music/vol-12.mp3 && cd ..

# Init the composition
cd composition && npx hyperframes init --width 1080 --height 1920 --fps 30 --duration 22

# Author index.html following ../composition-brief.md (typography rules, safe zone,
# Google Fonts preload for Fraunces + Plus Jakarta + 8 Noto Sans Indic families,
# 7 scenes clipped at the timings in ../script.md)

# Lint and validate
npx hyperframes lint
npx hyperframes validate

# Render
npx hyperframes render --output ../brag.mp4
```

## Must-have implementation reminders

- Load all 8 Noto Sans Indic fonts + Fraunces + Plus Jakarta in `<head>`; warm each with a hidden off-screen glyph before scene 1 to prevent font-swap flash.
- Root stage: `width: 1080px; height: 1920px; overflow: hidden;` — do not rely on responsive CSS.
- Vertical safe zone: keep all text between y=200 and y=1720.
- 8 sequential Indic phrase arrivals in scene 2: beat-grid at ~0.35s spacing, then HOLD the full stack 1.4s. Do not race the reading floor.
- Audio: `vol-12.mp3` at `data-volume="0.30"`, fade-in 0.4s at 0.0s, fade-out 0.6s ending at 22.0s.
- One audio-reactive element only: tangerine radial glow behind hero word in scene 1, opacity 0.15↔0.25 driven by bass RMS.
- Beat-lock 3 major moments (±0.15s): logo (~6.0s), moat overlay (~14.0s), scale-punch on `their` (~19.5s).
- No side-by-side layouts — vertical is one column per moment.
- All Indic copy is UTF-8; verify byte-for-byte match to `../script.md` before render.
