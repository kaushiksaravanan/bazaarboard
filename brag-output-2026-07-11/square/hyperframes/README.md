## Native-script rendering — non-negotiable

Every Indic phrase in the composition MUST render with the correct Noto Sans variant and preserve its diacritics:
- Devanagari: nukta on `पल्प`, matra placement, virama
- Tamil: pulli marks
- Malayalam: chillu letters
- Kannada: subjoined-consonant forms (kagunita)
- All: correct conjuncts

If a Google Fonts fetch fails at render time, fall back to a locally bundled Noto Sans family. Do **NOT** fall back to a Latin font — the entire premise of the video is that Indic scripts render correctly.
